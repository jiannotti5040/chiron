# A287616 claimed-proof audit

**Status: provenance and statement-equivalence audit only.** This is not an
independent proof reproduction, a solved-status claim, or a public submission.

## Why this case matters

The pinned DeepMind Formal Conjectures snapshot still labels the following
statement research-open:

- upstream: `google-deepmind/formal-conjectures`
- commit: `f776d2f2039351b00737ffcafb9d7d7666e1d9af`
- file: `FormalConjectures/OEIS/287616.lean`
- file SHA-256: `8902d91c56a3e5bcc6811f5013d7577d0e2f05897dee9b684b348830e52d30ae`

It asserts that every nonnegative integer is a sum of a triangular number, a
second pentagonal number, and a second heptagonal number, with all three
parameters nonnegative.

On 2026-06-24, [arXiv:2606.26035](https://arxiv.org/abs/2606.26035) claimed to
prove exactly that nonnegative-integer statement and to settle OEIS A287616.
The arXiv abstract expressly says that two results remain outside its Lean 4
formalization: one externally cited theorem and one symbolic-computation
statement. [OEIS A287616](https://oeis.org/A287616) now links the preprint but
still presents positivity as a conjecture.

Static inspection confirms that the artifact's theorem has the same domain,
quantifier order, and three polygonal summands as the Formal Conjectures
statement. Its source contains no theorem or lemma declaration proved with
`sorry` or `admit`, but it deliberately declares these two nonstandard axioms:

1. `genus_primitive_local_global` — a cited genus/local-global input.
2. `fin_cell_residual` — the residual finite descent claim, described by the
   authors as relying on an external exact-computation certificate.

The latter source comment describes roughly `3.4 × 10^10` exact-rational
subcell checks. The artifact's own `AxiomCheck` target is intended to print
these dependencies. This is useful, transparent evidence of the remaining
trust boundary; it is not evidence that either axiom has been independently
verified here.

No artifact code was copied into this vault. The inspected checkout did not
include a top-level license file, so any future reuse would first need an
explicit license check.

## Reproduction attempt

The published commands are `lake exe cache get`, `lake build`, and
`lake build A287616.AxiomCheck` using Lean `v4.29.0` and Mathlib `v4.29.0`.
An isolated temporary Lean setup was attempted. The targeted build did **not**
reach elaboration: the temporary data volume ran out of free space while
materializing Mathlib configuration files. The generated toolchain and package
cache were removed afterwards; the pinned source checkout remains clean.

Therefore the only completed checks are static source/provenance checks. Do
not write “Lean build passed,” “proof reproduced,” or “A287616 solved” based on
this audit.
