## Methodological limitation: every answer is the same

Every certified curve enclosed the same square, [1]. That is expected — non-trivial Sha is rare at rank 2 in this conductor range — but it means **this sweep does not exercise the non-trivial-Sha path at all**. A bug that forced the quotient to 1 (a dropped Tamagawa factor, a period off by a constant, a regulator scaled wrong) would produce exactly this table and nothing here would catch it.

What does constrain that: the same period/torsion/Tamagawa code path reproduces `Sha_an = 4` for 571.b1 in `../exact_rank0_sha/`, and the unsaturated controls return 1/4 and 1/9 rather than 1 — so the pipeline demonstrably can emit values other than 1.

**The missing test was attempted and not found.** `hunt_nontrivial_sha.py` screens with PARI's own floating quotient (a search heuristic, never evidence) and hands any candidate far from 1 to the exact certificate. It screened **1,443 rank-2 curves** over an a-invariant box of radius 26 with conductors to 400,000 and found **none** with `Sha_an > 1.6`.

That null result is only worth stating because the screen was checked against its own blind spot: fed deliberately unsaturated bases for 389.a1 it returns 1, 1/4 and 1/9 for index 1, 2 and 3, so it is not structurally pinned to 1. Non-trivial Sha at rank 2 is simply rare in this range. Certifying such a curve remains the strongest missing test; it will need a targeted source of candidates rather than a box scan.

## What a CONSISTENT row does not mean

It does **not** mean `#Sha` equals the enclosed square. The enclosure is equally satisfied by a nearby non-integer, and integrality of the quotient is exactly what BSD asserts and what remains unproved in rank 2. The one-way content is real though: had a ball missed every integer, that would have been a refutation.
