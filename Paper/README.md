# Abstain or Prove

`abstain_or_prove.tex` / `.pdf` — the project's paper: an engine that recovers
exact generators, proves them on withheld data, and refuses otherwise; the
external falsification (repunits) that tested the claim; and the certify gate
built on top. All numbers in the paper are reproducible by the commands in the
repository's gate battery.

Compile: `pdflatex abstain_or_prove.tex` (twice, for references).
